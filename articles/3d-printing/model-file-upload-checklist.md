# Before You Upload a 3D Model: Files, Scale and Versions

The file you send should identify exactly what you want printed. A folder containing several models called “final” can be difficult to interpret, especially if small changes affect how parts fit together.

## Use clear file names

Choose names that describe both the part and revision, such as enclosure-base-v3 or display-stand-v2. Keep an accompanying list of quantities. If an older version is included for comparison, label it clearly as reference only.

NAVION 3D's shop lists STL, OBJ, PLY, 3MF, GLB and glTF uploads, with files converted and checked in its stated workflow. Upload acceptance does not by itself confirm that every detail of a model can be manufactured as intended. Explain anything that needs special attention.

## State dimensions outside the file too

Include the intended overall dimensions and units in your enquiry. Do not rely on a screenshot to communicate size. If the model contains multiple objects, explain whether they are separate parts, alternatives or an assembly shown for reference.

For a fit-sensitive project, add a drawing or measurement list. For example, identify the opening that must accommodate your existing switch and the space needed behind it. Do not ask the reviewer to infer those measurements from an unrelated product photo.

## Send a final version deliberately

Before approval, compare the quotation against your file names, quantities and dimensions. If you upload a revision after discussing the price, point out what changed and ask whether the quote or schedule needs updating.

Keep a copy of the exact approved files. That makes a future repeat order or revision easier to explain. When requesting changes later, describe the difference from that version instead of starting with an ambiguous “make it slightly bigger.”
