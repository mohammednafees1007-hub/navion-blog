# Personalised Name Keychains: What to Check Before Ordering

A personalised name keychain is a small gift with one detail that must be right: the name. Before ordering, confirm the exact spelling with the person who knows it best, especially when you normally use a nickname.

## Write the name exactly as you want it

Supply the full text and make any capitalisation preference clear. If you want a particular script, symbol or unusual character, ask whether it is supported before paying. Do not assume that every font or layout is available for every product.

Read the current [personalised name keychain page](https://shop.navionrobotics.com/personalised-name-keychains) for the available options. Product choices can change, so use the current listing when selecting colours and placing the order.

## Keep multiple names organised

For several gifts, create one row per recipient with their name, selected colour and quantity. Give each row a simple reference number so that a correction applies to the right item.

For example, write “Item 03: change the spelling to Nafees; retain the selected colour.” That is clearer than sending a new list without explaining whether it replaces the previous one. Ask for acknowledgement of any change before production begins.

## Plan for the occasion

If the gift is for a birthday or farewell, state when you need it to arrive. Confirm production and delivery timing before treating an order as ready for that occasion. If gift packaging or a message is important, ask whether it can be provided rather than assuming it is included.
