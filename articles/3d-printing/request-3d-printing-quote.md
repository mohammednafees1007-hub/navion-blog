# How to Request a Useful 3D Printing Quote

A useful printing quotation starts with a clear description of the job. Sending a picture and asking “How much?” can begin a conversation, but it may not provide enough information to price the finished part.

## Send the model and explain its purpose

NAVION 3D reviews project files before confirming the final quotation. Upload your model through the [printing request page](https://shop.navionrobotics.com/3d-printing), then explain what it will be used for. A display piece and a part that connects to existing hardware need different discussions.

Include the intended dimensions and units. If you need several parts, name them individually and give a quantity for each. Mention which surfaces will be visible and which dimensions matter for fit. If you have a drawing, identify the critical measurements on it.

## Copy this enquiry format

- Project: what I am making and why.
- Files: the model names and version I want printed.
- Size: overall dimensions in millimetres.
- Quantity: number of each part.
- Fit: components or openings that must match.
- Preferences: material and colour, if known.
- Deadline: when the parts must arrive.
- Delivery: town and PIN code.

For example: “Two enclosure halves for a college demonstration. The board must fit inside, and the cable exits through the side. The drawing marks the board dimensions. Please confirm suitability before printing.” This is an illustrative enquiry, not a completed NAVION order.

## Check what the quote covers

Before accepting, confirm the selected file version, quantity, material, delivery charge and expected timing. If design changes or assembly are needed, ask whether those services are available and separately charged.
