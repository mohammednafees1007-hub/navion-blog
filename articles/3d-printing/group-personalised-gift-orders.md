# Planning Personalised Gifts for a Group or Event

Ordering gifts for a group creates a different challenge from choosing one present. The main risk is losing track of small details: one spelling correction, two identical names or a colour change that applies to only one person.

## Build one master list

Create a list with an item number, exact personalisation text, product, selected option and quantity. Keep this as the single current version. If several people are collecting preferences, combine their responses before sending the enquiry.

Use a simple format such as “07 | Asha | name keychain | selected available colour | 1.” This is an organisational example; confirm the actual product options against the catalogue.

## Confirm feasibility before collecting promises

Send the total quantity and required arrival date to NAVION 3D. Ask whether the request can be fulfilled and request a quotation. Do not assume a quantity discount, special packaging or a particular completion date unless it has been confirmed.

If every item must match, explain which details matter: product version, colour or presentation. If alternatives are acceptable, identify them early. That helps the discussion remain specific if a preference is unavailable.

## Control changes after review

Have the organiser check the entire list before approval. For subsequent changes, refer to the item number and explain exactly what is being replaced. Confirm whether the change can still be made and whether it affects timing or price.

Decide whether the order will go to one address or whether separate deliveries are being requested. Ask what arrangements are available and how they are priced. Leave time to check the received quantities before the event.
